# 上海2026秋新版四上数学练习

## 版本和范围

配套对象是上海教育出版社《义务教育教科书（五·四学制）数学 四年级上册》2026秋新版。出版社公布的封面为2024年审核通过版本；本次没有额外声称未核对的版权页月次和印次。

公开新版目录与旧试用本有明显区别，已核对为：

1. 运算关系与运算律
2. 四面八方的学问
3. 整数的四则运算与应用题
4. 大数的认识与改写
5. 度量衡的故事
6. 分数的初步认识
7. 线与角
8. 数学广场
9. 复习

用户选择按前半学期准备期中卷，当前期中覆盖第1–4单元，卷名和页面明确标出；期末覆盖全册第1–9单元。学校实际进度不同，可另行调整范围。

只归纳单元主题和基础方法，题目、例子和方位／角度图均为原创，不发布教材原页。用户提供的期中试卷用于了解题型与拓展思路，学生个人信息、作答、批注和照片不发布到网站。

## 题型、分层和计分

每卷32题、100分，前30题为基础90分，最后2题为思维拓展10分：

| 类型 | 数量 | 分值 |
| --- | --- | --- |
| 选择 | 8 | 每题2分，共16分 |
| 填空 | 12 | 每题2分，共24分 |
| 计算 | 8 | 每题5分，共40分 |
| 基础应用 | 2 | 每题5分，共10分 |
| 思维拓展 | 2 | 每题5分，共10分 |

拓展参考了用户试卷中的两类方法，并使用新的数字与明确条件编写：

- 余数相同，用被除数的差和商的差求除数，再代回原式求余数。
- 用逆推法求原人数，再分析一人转组使人数差减少2，检验“少于”与“相等”的临界情况。

题目提供默认收起的思路提示，展开不扣分；交卷后显示分步解析及基础／拓展分项。没有要求学生提前使用方程或不等式。

在线按答题栏的最终答案计分，多栏题分别得分。纸上过程和选填的文字过程用于订正，不进行自动过程评分。分数用a/b输入，不强制约分，接受数值相等的分数；支持全角数字、规范千分位和题目已声明的单位。数位与计数单位按题意区别，例如“千万位”不能替代计数单位“千万”。学生答案只进行受限数字解析，不执行表达式或代码。

## 保存、权限和记录

`subject_practice.py` 使用每位学生、每个学科独立的 `subjects/<subject>/practice.sqlite3`。开始时保存完整私有考卷快照，之后修改目录不会改变已签发练习的题目与答案。未交卷接口不返回标准答案、接受答案列表或解析。

一个学科同时保留一份未完成练习。进入列表只显示“继续／放弃”的提示，不强制跳回旧题；答题时自动保存到服务器，并保留当前标签页的未完成备份。版本号阻止旧保存请求覆盖较新作答，单学生单学科文件锁与SQLite事务保护并发开始／交卷。重复交卷返回同一结果，不重复产生记录。

放弃会清除本次答案并取消续答，不生成成绩；之后的旧保存或交卷请求不会复活它。退出或切换账号会清空页面私有状态。家长可查看关联学生的已交答卷与记录，不能开始、修改、提交或放弃练习。

旧的学科 `records.json` 保留，列表合并已有记录与新SQLite记录；英语学习库和英语考卷不迁移、不混用。损坏的练习数据库返回暂不可用并保留原文件。

## 重建材料与校验

```sh
python3 scripts/build_math_grade4_content.py
python3 scripts/build_math_grade4_materials.py
python3 scripts/build_assets.py
```

首个脚本生成目录、两套私有题目、两份知识点与三张原创SVG；第二个脚本需要ReportLab、pypdf和系统中文字体，生成含答案解析的PDF学生卷及知识手册。知识点和试卷的链接位于数学站对应卡片，所有内容按同一份JSON生成。

测试包括正确答案和分层分数、严格转组边界、数位概念、等值分数、部分得分、请求权限、私有快照、保存版本、并发、交卷幂等、放弃、损坏数据保护和真实前端流程。PDF会渲染全部页面，检查公式字符、插图、计算留白和拓展区域。
