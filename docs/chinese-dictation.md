# 生词默写

语文站的“生词默写”用于纸笔练习：家长或学生按课文录入一次词语，之后由设备朗读，学生自己掌握书写节奏。无需家长逐个报词，不自动判分。

## 使用

1. 选择课本、展开单元并选择课文。目录默认收起，也可添加自己的课文。
2. 输入词语，可用空格、换行、逗号、顿号或分号分隔；相同词语保留首次出现的一项。
3. 多音字可单独一行写 `薄｜单薄的薄`，左边为要写的词，右边为朗读内容。建议先试听，按老师要求核对读音。
4. 保存词表，或“保存并开始默写”。每词默认读两遍，正常语速，可选择读一遍或打乱顺序。
5. 开始后词语隐藏，学生在纸上写。点击“播放本词”开始；读完后会等待，写好再点“下一个”或按空格。首次空格播放当前词；长按空格或朗读中按键不会跳过词语。输入框内空格保持正常输入。
6. 结束后显示词语供自行核对，可勾选想再练的词语。中途可退出，回来时自主选择继续或结束，不强制进入旧状态。

## 语音

首版使用浏览器提供的普通话语音，语速为1.0。不调用英语Piper模型，不使用第三方课文录音。语音质量和可用性取决于设备、系统及浏览器；部分系统语音可能需要网络。页面只提供识别为普通话的声音；没有可用语音时明确提示安装普通话语音或更换支持的浏览器，仍可录入和保存词表。

## 保存与权限

家长可维护并播放关联学生的词表，学生登录后读取同一份；不同学生互相隔离。词表按课本和课文保存在 `user_data_simple/<学生>/subjects/chinese/dictation.sqlite3`，不写入考试、分数或英语学习记录。读取空词表不创建数据库。

采用严格 `base_revision` 版本校验，并发编辑返回409；本机未保存内容保留供复制、查看云端稿，明确确认后才能放弃本机修改。未同步草稿和中途进度按学生身份隔离；导航、注销和切换账号会停止声音并清除可见私人内容。

接口前缀 `/api/subjects/chinese/dictation`：

- `GET /books`、`GET /lessons?book_id=...`：内置与自建目录。
- `POST /lessons`：添加私人课文。
- `GET /wordlists?book_id=...`：本册词表摘要。
- `GET /wordlists/<book_id>/<lesson_id>`、`PUT` 同路径：读取与保存词表。

每课最多200个去重词语，每词最多40个字符，朗读内容最多100个字符。
