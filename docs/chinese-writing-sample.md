# 作文专项第1题：一次有趣的课间游戏

语文站“作文专项”提供这一题的完整练习。学生可使用给定材料，也可换成自己的课间经历；先写关键词，再写段落和修改稿。首版使用分层提示、自查和版本对比，不请求AI服务。

## 学习流程

1. 审题选材：确定人物、时间、游戏与最有趣的一刻；材料取舍和结尾想法选填。
2. 搭提纲：调整段落卡片、填写段落作用、标记重点；支持新增、移动和删除。已写正文会保留在“未归入提纲”的区域，可恢复。
3. 写重点段：先展开标记的段落，按需要使用动作、对话或反应。
4. 连成初稿：补齐其他段落，可通读全文。
5. 分轮修改：先看内容与顺序，再检查表达、字词和标点。每轮写一句修改理由，或确认检查后不需要修改。
6. 回看成果：对比初稿与修改稿，说明一次收获，保存作品。完成稿只读，可同题另开练习。

提示和参考提纲默认收起，不自动填入学生正文。段数和字数不决定成绩，作文没有标准答案匹配或百分制评分。

## 保存和权限

- 草稿自动保存，保存并退出会等待最近一次输入获得云端确认。
- 首页显示练习列表，由学生选择继续或新开一次，不强制恢复旧编辑状态。
- 保存提纲、初稿、内容修改稿、修改稿和完成稿等关键版本。恢复前额外保存当前草稿，已有版本继续保留。
- 并发保存采用严格的 `base_revision` 校验。冲突时保留本机稿，允许复制并查看云端稿，不盲目覆盖。放弃本机未同步修改需要明确二次选择。
- 账号切换立即清空可见文字。未同步内容按学生和练习编号隔离，只有相同身份、通过服务器归属校验后才提供恢复入口。
- 家长查看关联学生的过程和版本，全部写操作由服务器禁止。
- 作品完成后进入语文学科的学习记录，可再次查看；不写入英语或数学数据。

## 文件与接口

教学内容：`subject_content/chinese/writing/lesson-01-game.json`。新练习保存创建时的题目快照；后续调整教学内容不会改写已有练习。

学生数据：`user_data_simple/<学生用户名>/subjects/chinese/writing.sqlite3`。数据库使用事务保存当前草稿和不可变版本，读取空列表不会创建数据库。

接口前缀：`/api/subjects/chinese/writing`，复用原有认证与家长关联规则：

| 接口 | 用途 |
| --- | --- |
| `GET /lessons`、`GET /lessons/<id>` | 题目列表和教学提示 |
| `GET /attempts`、`POST /attempts` | 查看练习、自主新开练习 |
| `GET /attempts/<id>`、`PATCH /attempts/<id>` | 恢复与保存草稿 |
| `POST /attempts/<id>/checkpoints` | 保存关键版本 |
| `POST /attempts/<id>/complete` | 保存完成稿 |
| `GET /attempts/<id>/versions/<version_id>` | 读取历史版本 |
| `POST /attempts/<id>/restore` | 保存当前版本后恢复所选稿 |

保存、检查点、恢复、完成均要求当前 `base_revision`；冲突返回409。完成稿禁止继续覆盖，学生通过另开练习继续练习。

## 验证

后端测试覆盖保存恢复、并发冲突、题目快照、完成稿保护、版本恢复、家长权限、用户隔离和记录聚合。前端测试覆盖延迟响应、保存队列、退出期间输入、本机恢复选择、提示与段落操作、修改过程及完成流程。

可运行：

```sh
python3 -m pytest -q test_subject_writing.py test_subject_writing_ui.py test_subject_portal.py
node --test test_subject_writing_ui.js test_subject_portal_ui.js
python3 scripts/build_assets.py --check
```
